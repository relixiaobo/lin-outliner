# Tasks

The single live board across all clones — what is in flight, what is queued, and
a short record of what just shipped. **Owned by the main agent**
(`lin-outliner/`); the main agent updates it on merge. Dev agents *read* it at
plan time for the collision self-check and *claim* work by opening a Draft PR
(scope in the body) — they do not edit this file.

The live radar is `gh pr list` (open claims) **plus** this board; there is no
hand-maintained agent-status table — a table that needs manual refreshing is
wrong exactly when it matters (retired 2026-08-06 after listing two building
agents as idle). This board is the single source of plan status and priority:
every active plan has an entry here linking to its design in
`docs/plans/<topic>.md` (standing authorities in `plans/reference/`, terminal
plans in `plans/archive/`). Completion retrospectives live in `CHANGELOG.md` and
the merged PRs; distilled engineering rules live in [`lessons.md`](lessons.md).
The `bun run docs:check` guard keeps this board and `docs/plans/` consistent.
See `AGENTS.md` for the full workflow.
